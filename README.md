🔍 CO1 Reflection

Creating the concept map helped in understanding how different cloud computing technologies are connected. It showed how virtualization enables efficient resource utilization, while service models define the responsibilities of cloud providers and users.

The mapping also improved my understanding of APIs, web services, scalability, elasticity, and cloud service selection. Connecting these concepts visually made the overall cloud architecture easier to understand and analyze.
